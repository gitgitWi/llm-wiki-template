# celld 발표 — 자체 호스팅 분산 Durable Objects

## 발표 내용 요약

Ryan Dahl(Node.js·Deno 창시자)이 **celld** 를 공개했다. Cloudflare 의 Workers 와 Durable Objects 를 자체 호스팅으로 구현한 것이다.

- 구성 요소: V8 + S3 + SQLite + LTX + Tokio
- Cloudflare Workers/DO 의 JavaScript API 와 설정을 **그대로** 쓴다
- 대규모에서 비용이 한 자릿수 배수 이상 저렴하다고 주장
- 쓰기는 확인 응답 전에 내구성이 확보된다 — RPO=0
- S3 호환 버킷 외의 인프라 의존이 없다
- cell 인스턴스당 메모리 오버헤드 약 4MB, 휴면 cell 은 S3 저장 비용만 든다
- Apache 2 오픈소스

## DST 인용에 대한 확인

[[2026-08-20-ewind-dev]] 는 "Ryan Dahl 이 celld 를 이야기할 때 DST 를 언급했다" 고 인용한다. 확인 결과:

- **발표 트윗 본문에는 DST 언급이 없다.** 위 기능 목록이 전부다.
- DST 를 진지하게 적용한 뒤에야 설계가 자리를 잡았다는 발언은 **후속 발언으로 전해진다.** 스레드 전문은 직접 확인하지 못했다.

즉 방향은 맞지만, 인용의 근거 강도는 원문이 암시하는 정도보다 약하다. 1차 출처로 쓰려면 후속 발언을 직접 확인해야 한다.
