대상: `$ARGUMENTS`

공개는 되돌리기 어렵다. 한 번 공개된 내용은 이미 복제·인덱싱됐을 수 있다. **체크리스트를 통과하지 못하면 전환하지 않는다.**

## 체크리스트

문서를 읽고 항목별로 판정한다. 하나라도 걸리면 이유를 설명하고 멈춘다.

1. **개인정보** — 실명, 연락처, 소속, 평가 내용, 제3자에 대한 사적 언급이 있는가
2. **회사 정보** — 회사 내부 문서·코드·고객·매출·비공개 일정이 있는가
3. **저작권** — 외부 원문을 그대로 옮긴 부분이 있는가. 인용은 짧아야 하고 출처가 붙어야 한다
4. **출처 표기** — 외부 소스에 기반한 내용에 `source.url` 이나 본문 링크가 있는가
5. **private 링크** — 이 문서가 `visibility: private` 문서를 `[[링크]]` 하고 있는가
   → 공개 후 깨진 링크가 되거나 제목이 노출된다. 링크를 걷어내거나 대상도 함께 공개해야 한다
6. **`raw/` 노출** — `raw/` 파일 내용을 길게 인용하고 있는가. 원본은 공개 대상이 아니다

## 전환

전부 통과하면:

- `visibility: public` 으로 변경
- `updated` 를 오늘 날짜로 갱신
- `wiki/index.md` 에 공개 표시가 필요하면 반영
- `wiki/log.md` 에 기록:

```markdown
## [YYYY-MM-DD] publish | <문서 제목>
- wiki/<path>.md → public
```

## 걸렸을 때

어떤 항목에 왜 걸렸는지, 어떻게 고치면 공개 가능한지 알려준다. 사용자가 판단해서 다시 요청하면 재검사한다.

사용자가 "그냥 공개해"라고 해도 **6번(raw 원문)과 2번(회사 정보)은 다시 한 번 확인**받는다. 나머지는 사용자 판단을 따른다.
