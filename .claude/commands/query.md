질문: `$ARGUMENTS`

## 1. 진입점은 index

먼저 `wiki/index.md` 를 읽는다. 전체 파일을 grep으로 훑기 전에 카탈로그부터 본다 — 그러라고 있는 파일이다.

index에서 관련 페이지를 고르고 드릴다운한다. 필요하면 링크를 따라 더 들어간다. index로 부족할 때만 `Grep` 으로 본문을 검색한다.

## 2. 답변

- **인용을 붙인다.** 모든 주장에 근거 페이지를 `[[링크]]` 또는 파일 경로로 표시한다
- 위키에 없는 내용이면 **없다고 말한다.** 추측으로 채우지 않는다. 대신 어떤 소스를 넣으면 답할 수 있는지 제안한다
- 위키 내용이 오래됐거나 소스 간 충돌이 있으면 그 사실을 함께 알린다

## 3. 축적 — 이 단계를 빠뜨리지 않는다

답변이 **재사용할 가치가 있으면** `wiki/synthesis/` 에 페이지로 저장한다. 비교표, 정리, 판단 근거 같은 것들이 여기 해당한다.

탐색 결과가 대화에만 남고 사라지면 위키는 자라지 않는다. 저장할지 애매하면 사용자에게 물어본다.

저장했다면:
- `type: synthesis`, `visibility: private` (기본값)
- 근거가 된 페이지들과 양방향 `[[링크]]`
- `wiki/index.md` 에 추가
- `wiki/log.md` 에 추가:

```markdown
## [YYYY-MM-DD] query | <질문 요약>
- wiki/synthesis/<slug>.md 생성
```

단순 사실 확인처럼 저장할 필요 없는 질문이면 log만 남기거나 그냥 답하고 끝낸다.
